# One-Line Office Jokes

One funny line about office life, written by a pure-stdlib Python program for the make.fun bounty **One-Line Office Jokes**.

> Our Monday meeting opens with 'this will be quick' and closes by scheduling a follow-up meeting about why the last one took so long.
